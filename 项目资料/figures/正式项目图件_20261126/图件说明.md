# 正式项目图件说明

本目录图件均由 `scripts/plot_formal_project_figures.py` 使用 Python/matplotlib 生成，数据来自冻结正式结果和已完成的 100 条人工质量审计。PNG 为 300 dpi，图内使用正式中文题注。

| 图号 | 文件 | 正式题注与用途 |
|---|---|---|
| 图1 | `图1_项目技术路线.png` | RAG 幻觉检测项目技术路线：数据清洗、挑战构造、RAG 推理、证据核验、学习与消融、冻结评估。 |
| 图2 | `图2_有效证据重评分架构.png` | 有效证据 MiniCheck 重评分与轻量融合架构：公开规则筛选有效证据，再进行原 MiniCheck 重评分。 |
| 图3 | `图3_正式冻结测试方法比较.png` | 正式冻结测试的总体方法比较：有效证据 MiniCheck 的 AUC 为 0.893，超过自评和原 MiniCheck。 |
| 图4 | `图4_特征消融结果.png` | 轻量融合与特征消融结果：去词汇特征高于完整融合，去时间特征下降。 |
| 图5 | `图5_分组结果.png` | 三类挑战与正常条件的分组结果：检索失败组因共同事实单一而不计算 AUC。 |
| 图6 | `图6_人工质量审计.png` | 100 条分层人工质量审计：83 条答案正确、17 条不正确；6 条分歧已仲裁。 |

说明：图 3–5 使用已解盲冻结结果，只做展示，不用于重新调参；图 6 是质量审计，不替代独立双人金标。
