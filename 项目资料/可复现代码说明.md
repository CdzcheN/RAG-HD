# 可复现代码说明

## 环境

统一使用 Python 3.10 的 Conda 环境 `rag-c09`：

```bash
conda create -n rag-c09 python=3.10 -y
conda activate rag-c09
python -m pip install -U pip
python -m pip install -r requirements.txt
```

GPU 实验还需要本地模型权重、Hugging Face 数据授权和 CUDA 驱动。公开 MiniCheck 复现与本地 RAG 运行分别需要按《MiniCheck 复现指南》和《本地生成模型部署》准备缓存。

## 先做 CPU 验证

```bash
conda activate rag-c09
python -m unittest discover -s tests -v
```

当前仓库应通过 84 项测试。测试只检查构造约束、冻结门、划分隔离、评价统计和特征边界，不会重新生成最终测试回答。

## 主要入口

| 阶段 | 入口 | 说明 |
|---|---|---|
| MiniCheck 复现 | `scripts/reproduce_minicheck.py` | smoke、完整基准和离线分析 |
| 本地 RAG 原型 | `scripts/run_rag_prototype.sh` | BM25、生成、自评、MiniCheck |
| 正式来源准备 | `scripts/prepare_formal_inventory.py`、`scripts/prepare_formal_protocol.py` | 候选、清洗、来源隔离和冻结划分 |
| 正式开发推理 | `scripts/run_rag_formal_development.sh` | 仅开发集生成和评分 |
| 正式训练 | `scripts/train_formal_lightweight.py` | 只使用固定训练划分拟合 |
| 正式测试推理 | `scripts/run_rag_formal_test.sh` | 使用冻结模型和验证阈值，不训练 |
| 冻结预测 | `scripts/predict_formal_frozen.py` | 只读冻结模型和输入 |
| 正式评估 | `scripts/evaluate_formal_test.py` | AUC、AP、F1、bootstrap、置换检验 |
| 人工审计 | `outputs/rag_formal_20261105_v2/partitions/test/human_audit_100/` | 100 条分层质量审计，不回写最终指标 |

## 可复现边界

正式测试已经解盲。任何新方法不得使用最终测试标签、预测或分组结果调参。若继续研究，应重新准备独立来源和未见规则表达，重新冻结模型、阈值和测试集。

实验输出、数据来源、模型缓存和授权要求见 [`outputs/DATA_SOURCES.md`](../outputs/DATA_SOURCES.md)。正式结果见 [`results/rag_formal_final_20261105/README.md`](../results/rag_formal_final_20261105/README.md)。
