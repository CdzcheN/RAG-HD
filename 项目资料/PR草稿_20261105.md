## 问题与改动

本 PR 汇总 MiniCheck 基线复现及后续 RAG 实验，实现从受控挑战构造、来源清洗、回答复核到固定来源划分训练和冻结测试的完整流程。原型中的随机拆分不再用于正式实验；最终测试在开发标签、模型和验证阈值冻结后才可执行。

- 复现 MiniCheck-Flan-T5-Large：LLM-AggreFact 29,320 条、11 个子数据集，宏平均 BAcc 75.0093%，已完成离线核查。
- 部署本地 Qwen2.5-3B-Instruct NF4，构建生成、自评、原 MiniCheck、有效证据重评分及轻量融合/消融流程。
- 修复精确区间编辑、别名同步、数值联动、边界与单位约束，逐条清洗300个基础问题，准备600条输入（300挑战＋300正常）。
- 固定480条开发输入与120条最终测试，按来源与独占干扰材料隔离；三个种子各180训练/60验证组，共享固定60组最终测试。
- 增加测试冻结校验、15个模型/24个验证阈值的保存与检查，以及只读冻结预测评估、来源组bootstrap和置换检验。
- 归档阶段结果、复核来源说明、资源记录、完整最终指标和失败分析，并更新README与plan.md。

## 冻结测试结果

共同评估95条事实回答，其中14条幻觉正类；25条拒答保留undetermined。

| 方法 | ROC-AUC |
|---|---:|
| 生成模型自评 | 0.6071 |
| 原MiniCheck | 0.8042 |
| 有效证据MiniCheck | 0.8933 |
| 完整融合（三种子均值） | 0.8339 |

有效证据相对自评提升0.2862、相对原MiniCheck提升0.0891。完整融合未超过简单重评分；40条未见规则措辞全部回退为保留全部证据，没有获得筛选增益。这些负结果均保留。

相对原MiniCheck的来源组置换检验Holm校正p=0.0072；相对自评的置换检验p=0.1402，未通过0.05，尽管bootstrap差值区间为正。不宣称所有统计出口均显著。

## 范围与限制

- 标签来源是助手草稿经用户确认，不是独立双人标注；100条分层人工抽检的独立执行记录仍待补齐。
- 构造总计300条挑战，其中最终测试仅60条挑战＋60条正常；不将全部构造数据表述为独立测试。
- 验证正类仅3—5条，冻结阈值有迁移失败；不依据测试结果修改阈值或规则。
- 仅覆盖受控数量统计版本场景，创新性及跨任务泛化尚不能据此确立。
- 模型权重、下载缓存和原始运行输出遵循现有.gitignore保留在本地；仓库提交代码、构造配置及结果摘要。完整重跑评估需相应本地outputs产物和已授权的数据/模型环境。
- 本轮测试已解盲，后续方法改进须另留新的独立来源最终测试。
