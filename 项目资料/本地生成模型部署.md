## 直接运行一次本地问答

在主机终端执行，沙箱内可能无法看到 GPU：

```bash
cd /home/yqhe/project/rgzn/RAG-HD
.venv/bin/python scripts/local_qa.py \
  --question "What is the capital of the fictional region of Lumeria?" \
  --evidence "The fictional region of Lumeria has its capital in Bayport."
```

也可将 `--evidence` 换为 `--evidence-file /absolute/path/to/evidence.txt`。输出包括实际回答、模型提交、token 数、耗时与显存测量。该入口遵循只依据给定证据回答、证据不足时拒答的原型提示词。

## 重新准备和运行原型

当前机器的权重、数据与依赖已准备好。重建环境时，在 MiniCheck 基础环境中安装新增依赖，并下载配置指定的版本：

```bash
cd /home/yqhe/project/rgzn/RAG-HD
.venv/bin/python -m pip install -r requirements-rag.txt
.venv/bin/python -m pip check
.venv/bin/python scripts/rag_prototype.py --stage download \
  --run-dir outputs/rag_download_setup
```

首次下载需要访问 Hugging Face，后续推理只读本地文件。NLTK 分句资源沿用 MiniCheck 环境的私有目录，运行脚本默认设置为 `$HOME/nltk_data`。

选择新实验目录运行整个原型：

```bash
bash scripts/run_rag_prototype.sh outputs/rag_prototype_new_run
```

脚本依次执行 prepare → probe → generate → score → evaluate，各 GPU 阶段是独立进程。相同目录和配置可以继续运行，生成与评分按缓存键校验后复用，配置或缓存不匹配时明确失败。

默认配置为 `configs/rag_prototype.yaml`。它从两个固定训练集各取 200 条候选上下文建立受控语料，再各选 10 个问题，共 20 条。详细输入、标签和抽样边界见 [原型实验协议](RAG原型实验协议.md)。

## 查看进度及复核结果

最终验收运行目录：`outputs/rag_prototype_20261104_v1/`。首轮开发记录保存在不带 `_v1` 的目录，互不覆盖。

```bash
cat outputs/rag_prototype_20261104_v1/status.json
tail -n 0 -f outputs/rag_prototype_20261104_v1/logs/generate.log
```

`inference_complete_review_pending` 表示模型推理完成，但仍有回答需标签复核，不是推理失败；`*_failed` 表示对应阶段异常。生成日志停止更新后可查看 `score.log`、`evaluate.log` 及状态文件。

逐条结果位于 `records.jsonl`，统计位于 `metrics.json`。未取得可靠标签时 AUC 为空，不能将其解释为模型效果为零。

人工复核表为 `review_template.csv`，包含问题、实际可见证据、回答和参考答案，不含两种检测分数。建议复制一份填写：

```bash
cp outputs/rag_prototype_20261104_v1/review_template.csv \
   outputs/rag_prototype_20261104_v1/human_review.csv
```

对复核的行填写 `evidence_label`、`answer_correctness`、`review_source=human`、`reviewer` 和 `rationale`；未处理的行保持空白来源。保留样本 ID、输入/回答哈希及原始问题、证据和回答不变。标签及拒答处理遵守协议。完成后导入，不会重新执行模型推理：

```bash
.venv/bin/python scripts/rag_prototype.py --stage evaluate \
  --run-dir outputs/rag_prototype_20261104_v1 \
  --review outputs/rag_prototype_20261104_v1/human_review.csv
```

程序也接受同字段的 JSONL。原始文本、权重、人工标注和大体积预测均保留在被 Git 忽略的本地目录；代码仓库只归档版本、统计与校验摘要。
