# MiniCheck 第一版轻量改进：开发实验

2026-11-05 已实现并完成运行。方法根据**公开可见的来源优先规则及有效日期**筛选证据，再用相同 MiniCheck 重评分；逻辑回归融合原始风险、词汇覆盖及来源/时间重评分差。原始模型、评分和生成回答不改动。协议及文献边界见[轻量改进开发协议](../../项目资料/轻量改进开发协议.md)。

## 完整开发样本的无需训练对照

以下均使用同一批 86 条有标签、两种基线可评分的回答，含 15 个幻觉正类。34 条拒答或未确定标签均保留在原始集合并排除本表。

| 方法 | ROC-AUC | AP |
| --- | ---: | ---: |
| 自评 | 0.629577 | 0.374612 |
| 原始 MiniCheck | 0.712676 | 0.533145 |
| 有效证据 MiniCheck（无训练） | 0.911737 | 0.878674 |

重评分相对原始 MiniCheck 的 AUC 增加 0.199061。这是用于开发该方法的同批数据，且规则格式显式，**不是正式独立测试增益**。不能据此宣布研究目标验收通过。

典型变化：第98条旧姓名风险 0.0288 → 0.9843，第100条旧年份 0.0350 → 0.9725；第62条受支持的酒店回答风险 0.9174 → 0.0578，第106条当前人口回答 0.8328 → 0.0430。对没有来源/时间规则的关系混淆，筛选器继续沿用原分数，例如餐馆/牡蛎问题未解决。

## 三个分组开发划分与消融

按来源组固定 60%/20%/20%，正常/挑战始终同组。标准化和模型仅用训练部分，阈值仅用验证部分。全部样本此前已用于人工复核和错误分析，所以这里只能称开发内部划分。各内部测试的实际有标签样本为 16/17/17 条，正类为 6/2/4 条。

| 方法 | seed 13 AUC | seed 42 AUC | seed 2026 AUC | 均值 ± 样本标准差 |
| --- | ---: | ---: | ---: | ---: |
| 自评 | 0.4917 | 0.7000 | 0.7115 | 0.6344 ± 0.1237 |
| 原始 MiniCheck | 0.9667 | 0.9667 | 0.9615 | 0.9650 ± 0.0030 |
| 有效证据 MiniCheck（无训练） | 1.0000 | 1.0000 | 1.0000 | 1.0000 ± 0.0000 |
| 全特征逻辑回归 | 0.9667 | 1.0000 | 1.0000 | 0.9889 ± 0.0192 |
| 去词汇组 | 0.8000 | 1.0000 | 1.0000 | 0.9333 ± 0.1155 |
| 去来源组 | 1.0000 | 0.9667 | 1.0000 | 0.9889 ± 0.0192 |
| 去时间组 | 0.4667 | 0.9667 | 0.8654 | 0.7662 ± 0.2643 |
| 仅原始分数的逻辑回归 | 0.0333 | 0.9667 | 0.9615 | 0.6538 ± 0.5374 |

内部测试的小子集与完整86条分布不同，不能把这两张表中的数值混作同一评估。全特征模型尚无证据优于简单有效证据重评分。seed13 的单分数逻辑回归在少量训练正类和分布差异下学到反向排序，是保留的实际失败实验；未为改善它重抽种子或调超参数。

全特征模型相对原始 MiniCheck 的来源组 bootstrap AUC 差区间，seed13 为 [-0.1818, 0.1250]，seed42 为 [0.0000, 0.1333]，seed2026 为 [0.0000, 0.1689]。未形成稳定的严格正下界，不宣称显著优于 MiniCheck。各完整指标、阈值、Precision/Recall、Macro/Micro-F1、混淆矩阵见对应 `seed_*_metrics.json`；三个种子不作为独立重复做 t 检验。

## 构造敏感性与限制

原先不看分数的构造复核中有 36 个 basic 配对，共72条，其中59条可评估（6个正类）。自评 AUC 0.638365、原始 MiniCheck 0.751572；新增方法的同集合结果见 `complete_pilot_comparison.json`。basic 冲突子集没有幻觉正类，AUC 不可计算；不能把“没有错误”改造成正类以补齐指标。

全部24个有构造边界的配对仍保留于全量报告；敏感性按固定构造质量规则同时保留或排除一对两条，不按某个检测器表现筛选。新特征不读取 audit、参考答案、金标支撑、条件标签和扰动位置。规则解析器目前依赖合成资料的明确格式，不适合直接声称自然 RAG 泛化。

时间感知核查已有相关文献，当前实现定位为工程改进候选，不能仅因考虑时间就宣称研究创新。下一步应修正缺少指代与别名链断裂的构造、增加具有可信标签的多样化来源冲突案例，并隔离新来源和未见规则表达，之后才开展正式≥300条挑战实验。

## 验证与产物

30 项 CPU 检查通过，覆盖公开输入与隐藏真值隔离、来源规则、时间边界、回退、多跳保留、分组隔离和训练标准化。原始 MiniCheck 全部预测逐条保持一致；未重跑生成模型，只追加75次 MiniCheck 调用，采样进程峰值3798 MiB，低于12288 MiB。共保存15个轻量模型和三个种子的划分、系数、阈值及逐条预测。

本地完整产物：`outputs/rag_improvement_dev_20261105_v1/`。可读案例表为 `基线与改进案例.csv`，不含技术 ID 或哈希。运行方式见开发协议。本目录只保存统计、版本、资源、测试日志和校验摘要，不提交完整语料、预测或模型文件。
