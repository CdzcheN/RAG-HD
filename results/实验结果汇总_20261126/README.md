# 实验结果数据汇总

本目录为绘图用数据包。数据从仓库现有 `results/` 和 `outputs/` 结果归档复制而来，没有重新训练、重新选择阈值、重新评估最终测试，也没有修改原始结果。

## 直接绘图文件

| 文件 | 内容 |
|---|---|
| `汇总/正式总体方法比较.csv` | 8 种方法的 AUC、AP、Macro-F1、Micro-F1、Precision、Recall 均值和种子标准差 |
| `汇总/正式总体每种子结果.csv` | 正式测试总体结果，按方法和种子展开，含混淆矩阵 |
| `汇总/正式分组比较.csv` | 正式测试的完整分组结果，含 overall、challenge type、dataset、措辞和质量分组 |
| `汇总/正式分组每种子结果.csv` | 去除 overall 后的分组逐种子结果 |
| `汇总/100条人工审计.csv` | 100 条分层人工质量审计结果，含标注者、分歧和仲裁字段 |
| `汇总/MiniCheck公开基准.csv` | 11 个公开基准子集的样本数和 BAcc |
| `汇总/正式阶段资源汇总.json` | GPU、显存和阶段耗时 |

## 关键字段

### 正式总体与分组结果

- `方法` / `方法`：方法名称；
- `AUC均值`、`ROC-AUC`：排序指标；
- `AP均值`、`AP`：平均精确率；
- `Macro-F1`、`Micro-F1`：固定验证阈值后的分类指标；
- `种子`：13、42、2026；
- `分组维度`：分组类型；
- `分组`：具体条件；
- `输入数`：该组原始输入数；
- `共同评估数`：该组实际进入共同评价的事实回答数；
- `幻觉数`：该组正类数；
- `TN`、`FP`、`FN`、`TP`：固定阈值下的混淆矩阵。

### 重要解释

- 最终正式总体共同集合为 95 条，幻觉正类 14 条；不要将三个种子当作三个独立测试集。
- 检索失败组因拒答较多，部分子组只有单一类别，AUC 可能为空；不要把空值填成 0。
- `AUC` 不依赖分类阈值，`Macro-F1`、混淆矩阵依赖各方法验证集阈值。
- 100 条人工审计是质量审计，不是每条均由两名标注者独立复核。

## 原始追溯

- `原始结果索引.csv`：562 个机器可读结果文件的原始相对路径；原文件仍保留在仓库原位置，避免重复占用空间；
- `汇总清单.json`：汇总文件、冻结边界和数据包状态。

## 推荐绘图顺序

1. 用 `正式总体方法比较.csv` 绘制方法 AUC/AP/F1 比较；
2. 用 `正式总体每种子结果.csv` 绘制三种子阈值和混淆矩阵；
3. 用 `正式分组比较.csv` 绘制挑战类型、数据集和措辞泛化；
4. 用 `MiniCheck公开基准.csv` 绘制公开基准复现结果；
5. 用 `100条人工审计.csv` 绘制标注正确性、分歧和分层覆盖；
6. 用 `正式阶段资源汇总.json` 绘制显存与耗时。
