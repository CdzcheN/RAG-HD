## 尚未通过的语义出口

数量格式、唯一文本槽位和来源分区正确，不代表题意及构造有效。300个提名中110个带有指代、比例或时长等自动提示；该提示既不是自动判错，也不代表其余190个已通过语义核对。

已实际核对10个来源案例，保留改写与约束理由，尚有290个待逐条检查。例子：

- 第26题把“2006年财产犯罪影响了Santa Monica人口的3.74%”问成“财产犯罪占犯罪的比例”，分母不一致，需改题。
- 第283题将Nelson County写成state，不能拿县人口回答州人口，拟保持两跳关系改为county。
- 第265题把距离Bukhara的25 km（16 mi）误接成培训学院到出生地的距离，且两种单位需要联动；当前不能直接构造时间更正。
- 第10题原文是more than 150个地点，不能无条件当成确切150个。
- 第7题须补出bombers，不能把247架轰炸机说成247个Air Fleet。

这10个案例的修改仍是助手来源检查记录，不是用户对正式数据的确认，也未产生任何实际回答的幻觉标签。当前没有一份被声明为完整验收的最终构造规格。不能据此启动600条正式推理。

预留干扰目前只排除了原始参考答案别名；时间／冲突规格决定实际新数值后，还须检查新旧值及相关实体别名均未泄漏到干扰，并复核改写后问题、单位换算、比例和时间范围。上述复核不能由检测分数替代。
