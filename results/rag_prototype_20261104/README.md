## 当前标签与结论边界

当前 20 条均保留 `evidence_label=undetermined`；其中 3 条是单列拒答，17 条事实回答需要人工复核。模型被要求生成简短事实句，数据集标准答案通常是短实体，因而整句 Exact Match 为 0；该诊断不能解释为 20 条全部答错，更不能当作幻觉标签。

本轮对自动标签采用保守规则：只有整个回答匹配标注答案、且全部金标支撑实际可见时才能自动确认 supported。其他情况不凭检测分数补标签。人工复核表中隐藏两种检测分数，并保存原始输入与回答哈希，导入时防止把旧回答标注套用到新回答。

可靠标签尚未形成，因此 AUC/AP 为空。当前验收通过的是本地部署、数据与检索、生成、自评、MiniCheck、缓存和指标入口；P2.5 的标签核验、挑战构造和改进效果仍待完成。
