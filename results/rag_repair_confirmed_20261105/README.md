## 已冻结的计算范围

确认前已经缓存60条有效证据特征、180条种子预测。确认后只导入标签、计算指标，不重新生成、训练、评分或选择阈值。15个模型文件及原验证阈值逐一校验；保留完整预测、输入对应关系、确认记录及程序版本。主对比不用本批重新调阈值，也没有挑选表现最好的种子。完整逐种子结果见 `方法比较.csv` 与 `confirmed_seed_*_metrics.json`。

## 分组、统计与边界

来源冲突挑战组仅1个正类，时间挑战组仅2个正类；检索失败挑战组大量拒答，唯一事实回答是第14条，因此没有正类，AUC/AP不可计算。分组报告保留null及原因，不补零。正常组没有正类，亦不可计算AUC。

按来源组对相同48条进行1000次配对bootstrap。有效证据方法相对原MiniCheck的三个95%百分位区间分别约[0.2663,0.6530]、[0.2745,0.6596]、[0.2807,0.6688]；每次约950—963次重采样含两类。区间在本批条件下为正，但仅有3个正类、使用受控显式模板、该批用于构造修复开发，不能据此宣称正式目标或普适统计显著性验收。完整融合相对简单有效证据方法的区间未显示稳定正增益。

当前方法适用于公开指定的来源优先级与版本有效区间，并未自动学会自然来源可信度或自然时间推理。仍需独立新来源、未见规则表达和正式隔离数据；正式批次不得混入旧20／120／60条及其已见来源。
